\xmusection{项目背景}{Research Background and Significance}
生物科技领域的快速发展和政策环境的日益复杂，使得针对生物科技领域政策论证的研究需要应对海量且多样化的数据资源。传统的信息收集和分析方法已不足以支撑迅速变化的政策论证需求，迫切需要一个集成多模态数据采集、存储、分析及智能报告生成的综合系统，以高效支持生物科技政策的信息管理和科学决策。生物科技发展政策论证数据库软件应运而生，旨在通过自动化的多源数据采集和深度分析，实现政策信息的全面覆盖和智能化处理。平台将支持文本、语音、图片、视频等多种形式的数据集成，通过定制化的爬虫技术，实现多模态数据的高效采集与管理，并提供实时监控和可视化分析功能，以保证数据获取的全面性和精确性。

\par 生物科技发展政策论证数据库软件系统应具备大规模数据采集、存储和分析能力，能够采集包括中国、美国、英国、欧盟、日本、韩国、澳大利亚、加拿大、俄罗斯等国家和地区，涉及但不限于脑与认知、脑机接口、生物材料、全球军事医学地理、核化生武器损伤医学防护、伤病救治、环境作业医学、仿生医学等相关方向的生物科技相关政策数据，并支持高效管理和存储百万级别的多模态数据，同时提供灵活的数据清洗、编辑和导入导出操作。通过分布式存储架构和先进的数据处理技术，系统确保数据处理的快速响应和存储的高效利用。此外，系统将利用自然语言处理和数据增强技术，对数据进行预处理和深度分析，为生物科技政策研究提供更高质量的基础数据。

\par 为提升政策分析的深度，生物科技发展政策论证数据库软件系统将集成生物科技领域的大语言模型，具备可解释性和智能推理能力。通过提示工程和思维链技术，系统能够基于领域特性精准回答复杂问题，并支持多用户交互，为政策研究人员提供智能化的知识推理和问题解答功能。大语言模型的高效部署方案确保系统在内网环境中的安全运行。系统还具备智能报告生成和推送功能，支持根据用户自定义策略自动生成报告，并通过大语言模型辅助生成专业的报告框架和内容。用户可在系统中灵活修订报告，并根据需求选择多种推送方式，确保信息传递的及时性和针对性。

\par 生物科技发展政策论证数据库软件系统的推出，将显著提升政策研究的效率与准确性，为政策制定提供系统化的支持。通过集成前沿的数据处理技术和大语言模型，将为生物科技领域的政策分析、推理和决策提供创新的解决方案，助力科学决策和研究的高效推进。

\par 针对本模块，系统将支持对用户自定义的策略进行增删改查管理，可支持多个的报告策略模板；支持基于用户自定义策略的自动报告生成；支持基于大语言模型的报告框架自动生成，利用大语言模型自动生成专业报告框架，支持用户对该框架进行编辑修订管理，支持综合自动生成和用户自定义模式集成智能生成报告框架；支持基于大语言模型的报告内容自动生成，支持针对框架中各个分项构建提示工程和思维链，自动生成分项报告详细内容；支持用户对所生成的报告内容进行修订；根据用户要求，支持有邮件服务器推送和无邮件服务器推送两种数据推送模式，支持进行多用户推送。

\xmusection{前端技术框架选型}{Front-end Technology Framework}

在现代Web开发中，前端技术是构建用户界面和实现交互体验的核心。它主要基于三大核心技术：HTML（HyperText Markup Language）、CSS（Cascading Style Sheets） 和 JavaScript。这三项技术共同构成了网页的基础结构、样式和行为逻辑，是所有前端开发的基石。本节将从HTML、CSS和JavaScript的基本功能和特点入手，逐步引出我们在项目中选用的具体框架——Vue3。

1. HTML: 网页的骨架
HTML 是用于定义网页内容的标准标记语言，作为前端开发的基础，它决定了网页的结构和语义。HTML 使用一系列标签来组织文本、图像、链接、表格等元素，并通过嵌套的方式形成文档的层级结构。例如，<h1> 标签表示标题，<p> 标签表示段落，而 <a> 标签则用于创建超链接。HTML5 的引入进一步丰富了语义化标签，如 <header>、<nav>、<article> 等，使得代码更具可读性，同时也对搜索引擎优化（SEO）起到了积极作用。

HTML 的核心作用在于为网页提供一个清晰的结构框架，但其本身并不具备样式或交互能力。因此，开发者需要结合其他技术来完成完整的前端开发。

2. CSS: 网页的外观
CSS 负责控制网页的视觉呈现，包括布局、颜色、字体、间距等方面。通过 CSS，开发者可以将内容与表现分离，从而实现更加灵活和一致的设计风格。CSS 的基本工作原理是通过选择器定位 HTML 元素，并为其应用样式规则。例如，可以通过类选择器设置某些段落的背景色，或者通过媒体查询实现响应式设计，确保网页在不同设备上都能有良好的显示效果。

CSS 的强大之处不仅在于它的灵活性，还在于它能够处理复杂的布局需求。随着 CSS3 的发展，许多新特性（如 Flexbox 和 Grid 布局）被引入，极大地简化了复杂页面布局的实现过程。此外，动画和过渡效果的支持也为网页增添了更多的动态美感。

3. JavaScript: 网页的行为
如果说 HTML 提供了网页的骨架，CSS 定义了网页的外观，那么 JavaScript 则赋予了网页生命和交互能力。JavaScript 是一种动态编程语言，能够操作网页的 DOM（Document Object Model），处理用户输入事件，并与后端服务器进行通信。通过 JavaScript，开发者可以实现动态更新页面内容、响应用户操作、验证表单数据等功能，从而使网页变得更加智能和互动。

JavaScript 的核心优势在于其异步编程能力。借助 AJAX 或 Fetch API，开发者可以在不刷新页面的情况下向服务器发送请求并获取数据，从而实现流畅的用户体验。此外，现代 JavaScript 还引入了许多新特性（如模块化、Promise、Async/Await 等），显著提高了代码的可维护性和开发效率。

主流的前端开发框架有 Vue3 和 React ，以下就二者选型展开介绍。

\par React 是一个由 Facebook（现为 Meta）开发并维护的开源 JavaScript 库，主要用于构建用户界面（UI），特别是单页应用（Single Page Application, SPA）中的交互式视图层。自 2013 年首次发布以来，React 因其高效、灵活和组件化的特性迅速成为前端开发领域的主流框架之一，被广泛应用于 Web 开发中。React 的核心设计理念是通过声明式编程和组件化架构，简化复杂用户界面的开发流程，同时提供高性能的渲染能力。

\par 在本系统中，我们选择了 Vue3 作为主要的前端框架。Vue3 是一个渐进式框架，具有轻量化、易上手的特点，一个Vue文件里同时囊括了一个页面所需要的Html， CSS, JavaScript文件，并同时提供了强大的功能支持。它允许开发者根据需求逐步引入状态管理、路由等功能模块，非常适合中小型项目以及快速迭代的开发场景。我们在项目中使用了 Vue3 的特性之 Composition API （组合式api），组合式api提供了更灵活的方式来组织和复用逻辑代码，特别适合处理复杂的业务逻辑和对话式流程引导。此外，Vue3 的性能优化特性（如基于 Proxy 的响应式机制和静态树提升）也确保了系统在高频交互场景下的流畅运行。

Vue3框架结合 HTML、CSS 和 JavaScript ,使得我们能够高效地实现报告管理模块的开发，满足系统的功能性需求和用户体验要求。


\xmusection{后端技术选型}{Back-end Technology and API Design}
\xmusubsection{编程语言及框架选型}{Back-end Technology Selection}
后端技术负责处理业务逻辑、数据存储和与前端的交互。简单来说，Java语言拥有如下特性：

1. 平台无关性
\par Java程序编写一次，可以在任何支持Java的平台上运行，这是通过Java虚拟机（JVM）实现的。JVM是一个可以执行Java字节码的运行时环境，它使Java程序能够在不同的操作系统上运行而无需重新编译。这种特性极大地提高了代码的可移植性和复用性。

2. 简单性
\par Java的设计目标之一是简单易用。它的语法类似于C++，但去除了一些容易引起错误的特性，如指针和多重继承。此外，Java提供了自动垃圾回收机制，减轻了程序员管理内存的负担。这使得开发者能够更专注于业务逻辑的实现。

3. 解释执行
\par Java程序首先被编译成字节码，然后由JVM解释执行。这种机制提供了一定程度的安全性和可移植性，同时也允许Java程序动态链接新的类库。尽管这种方式在某些情况下可能会影响性能，但随着即时编译技术（JIT）的发展，Java的执行效率已经得到了显著提升。

4. 多线程支持
\par Java内置了对多线程编程的支持，允许同时执行多个线程，从而提高程序的响应性和性能。Java提供了同步机制来控制对共享资源的访问，确保线程安全。这对于构建高并发的应用程序尤为重要。

5. 健壮性
\par Java的强类型机制、异常处理和垃圾回收等特性，提高了程序的稳定性和健壮性。Java的安全特性也保护程序免受恶意攻击，确保数据和应用程序的安全。这使得Java特别适合用于企业级应用开发。

6. 高性能
\par 尽管Java最初以解释执行的方式运行，其性能随着即时编译器（JIT）技术的发展而不断提高。现代JVM能够将频繁执行的字节码编译成本地机器码，从而显著提升执行速度。如今，Java的执行效率已经非常接近编译型语言如C++。

\xmusubsection{数据库系统选型}{Back-end Technology Selection}
在数据库选型方面，MySQL与PostgreSQL都是免费、开源、强大、且功能丰富的数据库。MySQL 是一个成熟的关系型数据库，广泛用于各种规模的应用，能够有效地处理百万级别的数据。其支持 ACID 特性，保证数据一致性、隔离性、持久性，并且拥有强大的查询和索引优化能力。而可靠性是PostgreSQL的最高优先级。它以坚如磐石的品质和良好的工程化而闻名，支持高事务、任务关键型应用。PostgreSQL的文档非常精良，提供了大量免费的在线手册，还针对旧版本提供了归档的参考手册。PostgreSQL拥有强大的社区支持，还有来自于独立厂商的商业支持。数据一致性与完整性也是PostgreSQL的高优先级特性。PostgreSQL是完全支持ACID特性，对于数据库访问提供了强大的安全性保证。介于以下几点原因，本项目选择MySQL作为数据库。

(1)性能优化
\par 索引：MySQL 支持多种类型的索引（如主键索引、唯一索引、全文索引、复合索引等）。对于百万级数据的存储，合理的索引设计是保证查询性能的关键。特别是常用查询字段、连接条件、排序字段等应建立索引。
查询优化：MySQL 提供多种查询优化手段，例如 EXPLAIN 命令帮助分析查询计划，使用合适的 SQL 查询语句优化查询效率。
分区表：对于大数据表，可以使用分区表技术（如基于时间、范围等条件进行分区）来提高查询效率，减少扫描数据的量。

(2)扩展性
\par 读写分离：可以通过 MySQL 的主从复制架构实现读写分离，减轻主库的负担，提高系统的可伸缩性。主库负责写操作，从库负责读操作，适合读多写少的场景。
\par 分库分表：随着数据量的不断增加，单一数据库可能成为瓶颈。可以采用分库分表的策略，将数据根据某些规则分散到多个库和表中，进一步提升数据库的扩展性。

(3)高可用性与容错
\par 主从复制：MySQL 支持主从复制，可通过配置多个从库来增强系统的负载均衡和容错能力，提高数据的可靠性。
分布式存储：采用minio分布式存储文件数据。

(4)支持大数据量
\par MySQL 已经被广泛用于处理大规模数据存储和高并发查询场景。通过适当的硬件支持、数据分区及分布式处理，MySQL 在项目预计50000条数据的处理上能够保持较好的性能。

\xmusection{开发环境与工具链}{Development Environment and Toolchain}
在本系统的开发过程中，我们采用了现代化的前后端分离架构，从前端到后端再到数据库均选用当前主流且成熟的开发技术和工具链。前端基于 Vue.js 3 框架配合 Vite 构建工具进行模块化开发，同时引入 TypeScript 提高代码的可维护性与类型安全性。通过使用 Vue 3 的 Composition API 和响应式系统，我们能够更灵活地组织和复用代码逻辑，提升了开发效率。界面组件库采用 Element Plus，它不仅提供了丰富的UI组件，还支持按需加载，减少了打包体积，提升了页面加载速度，保证了 UI 风格的一致性和美观度。

后端基于 Java 语言开发，采用 Spring Boot 框架构建 RESTful API 接口，并整合 MyBatis Plus 实现对数据库的高效操作。Spring Boot 提供了自动配置、简化依赖管理和强大的社区支持，极大地缩短了开发周期。MyBatis Plus 则在 MyBatis 的基础上增加了许多便捷的功能，如代码生成器、分页插件等，使得数据库操作更加简便和高效。整体开发注重代码规范与模块划分，采用分层架构模式（如Controller、Service、DAO层），提高了系统的可扩展性和可测试性。

为保障开发流程的规范性和团队协作的高效性，我们使用 Git 作为版本控制工具，通过 Gitee 平台进行代码托管与分支管理。我们遵循了 Git Flow 分支模型，确保了不同阶段（如开发、测试、发布）之间的隔离与协调。开发工具方面，前端使用 VS Code 配合 Prettier 和 ESLint 插件进行格式化与代码检查，确保代码风格统一并减少潜在错误；后端则使用 IntelliJ IDEA 进行服务端逻辑开发与调试，其智能提示、代码重构等功能显著提升了开发效率。

接口文档采用 Swagger 自动生成并集成在 Spring Boot 项目中，便于前后端联调和API测试。Swagger 不仅提供了友好的UI界面，还能自动生成API文档，大大减少了手动编写文档的工作量。数据库方面，选用 MySQL 作为主数据存储方案，并配合 Redis 实现缓存优化，使用 Navicat 作为图形化管理工具。MySQL 提供了稳定的关系型数据库支持，而 Redis 则用于缓存热点数据，显著提升了系统的读写性能和响应速度。

\par 大纲管理包括用户自定义大纲及大模型生成大框，每个报告框架的生成与修改都应记录操作时间和修改内容，并且可以通过框架ID查看变更历史。经与设计人员讨论决定分开两个前端页面进行展示以作区分，后端也对应分开API进行传输处理。

\xmusubsection{测试软件}{Testing}

(1)使用 JUnit 5 进行单元测试，使用 JMeter 5.4 进行性能测试。
(2)缓存：处理器缓存应至少为 20MB，用于存储经常访问的数据，减少从内存读取数据的时间，提高数据访问速度。
(3)内存：每台服务器配备 64GB 及以上的内存，以支持大语言模型的加载、数据处理和多用户并发操作时的内存需求。足够的内存可避免频繁的内存交换，保证系统性能。内存频率不低于 DDR4-3200MHz，以加快数据读写速度，提高系统整体性能。
(4)存储：采用高速固态硬盘（SSD）存储方案。用于存储系统关键数据和经常访问的数据，如操作系统、数据库索引等，以实现快速读写。每台服务器配备至少 1TB 的 SSD。
